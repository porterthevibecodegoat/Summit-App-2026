# App Store Checklist

Current readiness:

- App name and slug are centralized.
- Bundle identifier placeholder exists.
- EAS development, preview, and production profiles exist.
- Notification permission rationale exists in Expo config.
- No unused camera, contacts, microphone, photo, or location permissions are declared.

Before submission:

- Replace app icon and splash placeholders.
- Configure EAS project ID.
- Provide privacy policy URL and support URL.
- Complete privacy manifest/data inventory.
- Provide reviewer access for invite-only mode if enabled.
- Visually inspect on supported iPhone sizes.
